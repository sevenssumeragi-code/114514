# 🎬 BB劇場メーカー

淫夢・クッキー☆系の **BB劇場動画** を自動生成するツールです。
テーマを入力するだけのシナリオ自動生成、立ち絵・BGM・SEの自動割当、
既存動画のテンポ模倣までブラウザだけで動作し、インストール・ビルド・サーバー不要です。

> **⚠ 素材について**: 立ち絵・背景・音声素材は同梱していません(権利上の理由)。
> お手持ちの素材を手動で登録してください。動作確認用に、内蔵のプレースホルダ
> キャラ(まんじゅう風)とチップチューン風サンプル音源が自動で読み込まれます。

## 使い方

1. `index.html` をブラウザ(Chrome / Edge 推奨)で開く
2. 起動時にサンプルが読み込まれるので、まず **▶ 再生** でプレビューを確認
3. **シナリオ自動生成** にテーマを入れて「🎲 内蔵エンジンで生成」(またはClaude APIでAI生成)
4. 自分の素材に差し替える
   - **登場人物(2人)**: 表情ごとの立ち絵PNG(透過推奨)を「+ 立ち絵を追加」で登録
   - **背景(1〜3枚)**: 各スロットに背景画像を登録
   - **BGM / SE**: 音声ファイルをアップロードしてタグ付け → 場面ごとに自動割当
5. 台本を微調整して「台本を反映」
6. **🎥 動画を書き出す**(BGM/SE合成済みMP4) または **📦 AviUtl用データ** で出力

## シナリオ自動生成

- **内蔵エンジン(オフライン)**: テーマ+テイスト(コメディ/シリアス風/ホラー風/バトル風)+長さを
  指定すると、起承転結スケルトンから緩急とオチのある台本を生成。生成のたびに内容が変わります
- **AI生成(Claude API)**: 自分のAnthropic APIキーで、より自由度の高い脚本を生成
  (キーはブラウザのlocalStorageにのみ保存。ネットワーク制限環境では内蔵エンジンを使用)

## 動画から真似る(テンポ模倣)

既存のBB劇場動画(MP4/WebM)を読み込むと、ブラウザ内解析で以下を抽出します。

| 抽出対象 | 手法 |
|---|---|
| 場面転換(カット割り) | フレーム全体の差分スパイク |
| 会話のテンポ | 画面下部(字幕領域)の変化間隔 → セリフ長と間(ま) |
| キャラの入れ替わり | 画面左右の変化量から話者サイドを推定 |
| BGMの切り替わり | 音声のRMS/ゼロ交差率の変化点 |
| SEの頻度 | 短時間の音量スパイク |

「生成時にこの動画のテンポを真似る」をONにしてシナリオ生成すると、
場面数・セリフ数・各セリフの表示秒数・間・話者交代パターンが新しい台本に移植されます。

## 台本の書き方

```
# 行頭 # はコメント
@bg 1                          … 背景1に切り替え(1〜3)
@wait 1.5                      … 1.5秒の間(ま)を入れる
@bgm 緊張                      … ここからのBGMムードを手動指定
@bgm なし                      … BGMを止める
@se 衝撃                       … この位置でSEを鳴らす

先輩「おっ、来たか」            … かぎ括弧形式
後輩: 何なんですか?            … コロン形式(全角コロンも可)

先輩「ふざけるな!」(表情:怒り)  … 表情を手動指定
先輩「……」(時間:1.6)           … 表示時間を手動指定(秒)
先輩「よし」(表情:笑顔 時間:3)  … 併用も可
```

- 台本の名前は、キャラパネルの **キャラ名と完全一致** させてください
- 表示時間は文字数から自動計算されます(「…」や「、」は間として加算)

## 自動でやってくれること

| 機能 | 内容 |
|---|---|
| 表情の自動選択 | セリフの内容から感情(通常/笑顔/怒り/悲しみ/驚き/照れ/疑問/叫び)を推定し、登録済み立ち絵から最適な1枚を選択。該当表情が無い場合は近い表情で代用 |
| BGMの自動割当 | 場面の感情分布からムード(日常/コミカル/緊張/激しい/悲しい/感動/静か)を推定し、タグの合うBGMをクロスフェードで切替。`@bgm` で手動指定も可 |
| SEの自動割当 | 感情が動いたセリフの頭で、タグ(衝撃/ツッコミ/笑い/きゅん/悲しい/汎用)の合うSEを自動再生。`@se` で手動指定も可 |
| 表示時間の自動計算 | 文字数ベース+「…」「、」の間を加味。設定パネルで調整可能 |
| 立ち絵の演出 | 話者は明るく表示+発話開始時にぴょこっと跳ねる。非話者は自動で暗く |
| 字幕 | キャラ色の縁取り付き字幕+話者ネームプレートを自動配置。自動折り返し |
| 背景切替 | `@bg` でクロスフェード切替 |

立ち絵のタグはファイル名からも自動推測されます
(例: `hoge_怒り.png` や `angry.png` → タグ「怒り」)。

## 出力形式

### 🎥 動画 (MP4 / WebM)
ブラウザの録画機能(MediaRecorder)でプレビューをそのまま動画化します。
**BGM/SEも動画の音声トラックに合成されます。**
Chrome/EdgeならMP4、非対応ブラウザではWebMで保存されます。
実時間キャプチャのため、動画の尺と同じ時間がかかります。

### 📦 AviUtl用データ (.exo + 素材)
BB劇場制作の定番 **AviUtl(拡張編集)** にそのまま読み込めるZIPを出力します。

- `bb_theater.exo` … タイムライン(レイヤー1=背景 / 2=左キャラ / 3=右キャラ / 4=字幕 / 5=BGM / 6=SE)
- `assets/` … 使用した全素材(画像+音声)
- `README_AVIUTL.txt` … 取り込み手順

exo内の素材パスは書き出し時に指定したフォルダ(既定 `C:\bb_theater\assets`)を指すので、
そこに素材を置いてから .exo をタイムラインにドラッグ&ドロップしてください。
細かい演出の微調整はAviUtl側で自由にできます。

### プロジェクト保存/読込
素材画像・台本・設定をまるごと1つのJSONに保存し、あとで再開できます。
(ブラウザを閉じると作業内容は消えるため、こまめに保存してください)

## 技術構成

- 純粋なHTML/CSS/JavaScript(依存ライブラリなし・ビルド不要)
- `js/emotion.js` … 感情推定・立ち絵自動選択
- `js/audio.js` … 場面ムード推定・BGM/SE自動割当・Web Audio再生エンジン
- `js/scenario.js` … シナリオ自動生成(起承転結スケルトン+Claude API)
- `js/analyzer.js` … 動画解析(カット/字幕テンポ/話者サイド/BGM変化/SE検出)
- `js/parser.js` … 台本パーサ
- `js/timeline.js` … タイムラインコンパイラ(時間割付+音声割付)
- `js/renderer.js` … canvas描画(プレビュー/書き出し共通)
- `js/exporter.js` … MediaRecorderによる動画書き出し(音声トラック合成)
- `js/exo.js` … AviUtl .exo生成(Shift_JISリテラルを事前計算して埋め込み)
- `js/zip.js` … 依存なしの最小ZIP書き出し
- `js/samples.js` … サンプル素材の動的生成(立ち絵/背景/チップチューン音源)
